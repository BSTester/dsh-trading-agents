# 个股解读（stock_digest · 混合通道版）

参考富途官方 SkillHub 个股解读 skill 的输出形态：**结构化数据走工作台（quantwb），
新闻与情绪走只读通道**，两路汇总成一页纸解读。

## 数据通道

| 数据点 | 工具 | 说明 |
|---|---|---|
| 标的卡/账户模式 | `mcp__quantwb__snapshot` | 工作台全量快照里的标的卡（A 股自动降级为日线收盘并注明"实时快照不可用"） |
| 标的解析 | `mcp__quantwb__instrument` | 名称/市场/整手；解读前先解析 |
| K 线 | `mcp__quantwb__series` | 近期走势与位置（默认日线 120 根） |
| 因子打分 | `mcp__quantwb__factors` | 横截面因子分（估值/质量等维度），给出相对强弱 |
| 数据质量 | `mcp__quantwb__quality` | 缺口/复权口径报告；**有缺口的维度必须在解读中标注，不基于缺口数据下结论** |
| 事件时间线 | `mcp__quantwb__events` | 公告/分红/披露事件，解读的锚点 |
| 新闻（只读） | `fin_news`（首选）或 `mcp__futu__quote_news_search`（注意空结果陷阱，见 docs/TOOL-LIMITS.md） | 信息面要点 |
| 情绪（只读） | `fin_sentiment`（首选）或 `mcp__futu__` 社区类只读工具 | 情绪面要点；渠道缺失如实标注 |

- 混合纪律：工作台数据与只读通道数据**分列标注来源**，不混算；两路都取不到的维度写
  "暂无数据"，不编造。

## 工作流程

1. `mcp__quantwb__instrument` 解析标的 → `mcp__quantwb__snapshot` 读标的卡与账户模式。
2. 并行取结构化数据：`mcp__quantwb__series`（走势）+ `mcp__quantwb__factors`（因子分）+
   `mcp__quantwb__quality`（质量）+ `mcp__quantwb__events`（事件）。
3. 只读通道补齐：`fin_news`（信息面）+ `fin_sentiment`（情绪面）；来源与时间逐条标注。
4. `mcp__quantwb__quality` 报告有缺口/复权口径差异时，在对应维度标注可信度限制。
5. **输出格式**（一页纸）：

   > **画像表**：维度（行情位置/因子分/质量/事件/新闻/情绪）| 要点 | 来源 | 数据时间
   > **摘要**：一段话综合解读（多空线索都要提，不诱导方向）
   > **关键信号**：后续跟踪清单（事件日、因子极值、情绪拐点）
   > 以上内容基于公开信息整理，不构成投资建议

## 安全

- 本技能**只读**，不下单、不改单、不撤单；综合解读必须正反两面都给，不构成投资建议。
- 用户据解读要求交易时：写操作唯一路径是工作台通道（见 `futu-trading` 技能：
  quantwb `trade_*` 工具 + 用户在独立 Web 确认卡片批准）；禁止经 `mcp__futu__` 或任何
  绕过工作台的方式下单。live 写通道未接入（当前仅 sim 可交易），如实说明。
