# 资讯搜索（news_search · 只读通道版）

参考富途官方 SkillHub 资讯搜索 skill 的信息面，**工作台当前没有新闻端点**（如实说明），
资讯走只读通道获取，模型负责检索、去重与摘要。

## 数据通道

| 数据点 | 工具 | 说明 |
|---|---|---|
| 标的解析 | `mcp__quantwb__instrument` | 把中文名/代码规范成检索用代码（如 `HK.00700`）；工作台在此技能里只承担解析，无新闻端点 |
| 新闻（首选） | `fin_news(ticker, name, count, lang)`（fin-data 插件原生工具） | 多源自动路由：富途快讯 → AKShare(A股) → Yahoo RSS(港美)，降级已内置于代码 |
| 新闻（备用，只读） | `mcp__futu__quote_news_search` | **已知坑**：实测对多数标的返回 `data: []`（见 docs/TOOL-LIMITS.md）——空结果不代表"没有新闻"，换 `fin_news` 或公开网络，不要据空结果下结论 |
| 公开兜底 | web 搜索 / Yahoo RSS | 前两层都取不到时使用，标注"数据源：公开网络，非实时" |

- 检索词纪律：中文标的中文名与代码各试一次；美股用英文专名；不编造未出现的新闻条目。

## 工作流程

1. `mcp__quantwb__instrument` 解析标的，确定市场与检索用名称/代码。
2. 按通道优先级取新闻：`fin_news` → `mcp__futu__` 只读（注意空结果陷阱）→ web 公开兜底。
   渠道间去重（同一事件多源报道合并，保留最早时间与最完整叙述）。
3. 按时间倒序整理，区分**事实**（公告、成交、监管）与**观点**（评级、评论），标注每条的
   来源与时间；超过 7 天的旧闻单独分组或剔除，不与最新消息混排。
4. **输出格式**：

   > **新闻表**：时间 | 标题 | 来源 | 类型（事实/观点）| 一句话要点
   > **摘要**：一段话概括当前信息面
   > **关键信号**：值得后续跟踪的事件（财报日、股东变动、政策窗口等）
   > 以上内容基于公开信息整理，不构成投资建议

## 安全

- 本技能**只读**，不下单、不改单、不撤单。
- 新闻时效与准确性以来源为准：摘要保留原文口径，不添加推测；无法核实的消息如实标注
  "未核实"。
- 用户据消息面要求交易时：写操作唯一路径是工作台通道（见 `futu-trading` 技能：
  quantwb `trade_*` 工具 + 用户在独立 Web 确认卡片批准）；禁止经 `mcp__futu__` 或任何
  绕过工作台的方式下单。live 写通道未接入（当前仅 sim 可交易），如实说明。
