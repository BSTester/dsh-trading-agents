# 情绪温度计（comment_sentiment · fin_sentiment 主通道版）

参考富途官方 SkillHub 情绪温度计 skill 的输出形态，**工作台当前没有情绪端点**
（如实说明）：社区情绪没有托管工具（富途侧无对应托管能力，不属工作台富途实时直通），
情绪数据由 `fin_sentiment` 一条通道获取，模型负责量化与解读。

## 数据通道

| 数据点 | 工具 | 说明 |
|---|---|---|
| 标的解析 | `mcp__quantwb__instrument` | 把中文名/代码规范成检索用代码；工作台在此技能里只承担解析，无情绪端点 |
| 情绪（唯一通道） | `fin_sentiment(ticker, x_query, count)`（fin-data 插件原生工具） | X 情绪 + A 股千股千评 + Reddit 聚合；渠道不可达自动跳过。首次使用 X/Reddit 需一次性登录（见 `trading-agents` 技能）。**保留原因：社区情绪无托管工具**（富途侧无对应托管能力） |

- 量化口径：正面/负面/中性占比按**样本条数**统计，附渠道构成与样本量；渠道缺失时
  温度读数必须降权并标注"样本偏斜"。取不到任何渠道时如实告知，不编造情绪读数。

## 工作流程

1. `mcp__quantwb__instrument` 解析标的，确定检索词（X 用英文、可组合 `$代码`；
   千股千评仅 A 股）。
2. `fin_sentiment` 取多渠道讨论；剔除水贴与重复转发，保留有信息量的发言。
3. 逐条归类情绪（正面/负面/中性），结合热度趋势（近期讨论量 vs 之前）给出温度读数
   （0–100，50 为中性），并摘出 3–5 条代表性观点（注明多空方向）。
4. **输出格式**：

   > **情绪表**：渠道 | 样本量 | 正面/负面/中性占比 | 热度趋势 | 数据时间
   > **温度读数**：N/100（附一句话解读与样本偏斜说明）
   > **关键信号**：情绪拐点、分歧加大、极端一致性等值得警惕的形态
   > 以上内容基于公开信息整理，不构成投资建议

## 安全

- 本技能**只读**，不下单、不改单、不撤单。
- 情绪指标噪声大、可被操纵，只作参考；极端一致情绪反而常是反向信号——解读时必须提示。
- 用户据情绪要求交易时：写操作唯一路径是工作台通道（见 `futu-trading` 技能：
  quantwb `trade_*` 工具 + 用户在独立 Web 确认卡片批准）；禁止经 `mcp__futu__` 或任何
  绕过工作台的方式下单。live 写通道未接入（当前仅 sim 可交易），如实说明。
