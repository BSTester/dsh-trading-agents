# 技术面异动（technical_analysis · 工作台对接版）

参考富途官方 SkillHub 技术面异动 skill 的分析框架，但 K 线数据走工作台通道，
**指标不依赖外部计算服务，由 Harness 用 K 线数据按下列公式自算**。

## 数据通道

| 数据点 | 工具 | 说明 |
|---|---|---|
| K 线序列 | `mcp__quantwb__series` | ticker/period/limit；自算指标建议 limit ≥ 120（暖机用），period 默认 `1d` 或 `60m` |
| 标的解析 | `mcp__quantwb__instrument` | 确认市场与代码格式（如 `00700.HK`、`SH.600519`、`AAPL.US`） |
| 备用 K 线 | `mcp__futu__quote_history_kline`（只读） | 工作台通道不可用时的降级；输出必须标注来源与时间 |

- A 股注意：实时快照/盘口类权限不可用（`-9 realtime quote permission required`，不是故障），
  技术面用日线/分钟 K 线即可，不要依赖实时报价。
- 工作台不可达且富途只读通道也不可用时：改用公开网络数据源，标注"数据源：公开网络，非实时"，
  或如实告知取数失败。不要编造指标值。

## 指标公式（Harness 自算，写全如下）

**MACD（12, 26, 9，国内口径）**

- EMA：`EMA_t = α × Close_t + (1 − α) × EMA_{t−1}`，其中 `α = 2/(N+1)`；
  首值 `EMA_N` 取前 N 根收盘价的简单平均。`α₁₂ = 2/13`，`α₂₆ = 2/27`。
- `DIF = EMA12 − EMA26`
- `DEA = EMA9(DIF)`（对 DIF 再做 9 周期 EMA，`α = 2/10`）
- 柱：`MACD = 2 × (DIF − DEA)`

**RSI（14，Wilder 平滑）**

- `Δ_t = Close_t − Close_{t−1}`
- `U_t = max(Δ_t, 0)`，`D_t = max(−Δ_t, 0)`
- 首值：前 14 根的简单平均 `Ū`、`D̄`；其后 Wilder 递推：
  `U_t = (U_{t−1} × 13 + U_t) / 14`，`D_t` 同式
- `RS = Ū_t / D̄_t`，`RSI = 100 × Ū / (Ū + D̄)`（`D̄ = 0` 时记 100）

**KDJ（9, 3, 3）**

- `RSV_t = (C_t − L9) / (H9 − L9) × 100`（L9/H9 为近 9 根最低/最高；`H9 = L9` 时 RSV 记 50）
- `K_t = (2/3) × K_{t−1} + (1/3) × RSV_t`，首值 `K₀ = 50`
- `D_t = (2/3) × D_{t−1} + (1/3) × K_t`，首值 `D₀ = 50`
- `J = 3K − 2D`

**异动判定基准**（输出时逐条对照）

- 金叉/死叉：DIF 上穿/下穿 DEA；柱由负转正/由正转负
- 超买超卖：RSI14 > 70 / < 30；KDJ 的 K、D 位于 80 上方 / 20 下方
- 低位金叉：K < 20 且 K 上穿 D；J > 100 或 < 0 的极端值
- 背离：价格新高/新低而指标不随之（至少两个峰/谷确认）

## 工作流程

1. `mcp__quantwb__instrument` 解析标的；与用户确认周期（默认日线）。
2. `mcp__quantwb__series` 取 K 线（limit ≥ 120，不足时如实说明指标可信度受限）。
3. 按上述公式计算 MACD / RSI14 / KDJ 最新值与前值，对照异动判定基准给出信号清单。
4. **输出格式**：

   > **指标表**：指标 | 最新值 | 前值 | 信号（金叉/死叉/超买/超卖/中性）| 数据时间
   > **摘要**：一段话概括趋势位置与动能方向
   > **关键信号**：触发的异动条目（含触发数值）
   > 以上内容基于公开信息整理，不构成投资建议

## 安全

- 本技能**只读**，不下单、不改单、不撤单。
- 用户据信号要求交易时：写操作唯一路径是工作台通道（见 `futu-trading` 技能：
  quantwb `trade_*` 工具 + 用户在独立 Web 确认卡片批准）；禁止经 `mcp__futu__` 或任何
  绕过工作台的方式下单。live 写通道未接入（当前仅 sim 可交易），如实说明。
- 指标基于历史价格，滞后性与失效风险如实标注；信号不构成投资建议。
