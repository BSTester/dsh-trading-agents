### 2.2 表迁移模式（单一实现，全 WP 共用）

- **新表**：追加进 `plugins/core/python/trading_core/store.py` 的 `_SCHEMA`（全部
  `CREATE TABLE IF NOT EXISTS`，幂等，SCHEMA_VERSION 递增到 4 由 WP9 落地后各 WP 沿用）；
- **已有表加列**：WP9 在 store.py 引入唯一 helper（后续 WP 只调用不重写）：

```python
def _add_columns(conn, table, cols):  # cols: [(name, decl), ...]
    have = {r[1] for r in conn.execute(f"PRAGMA table_info({table})")}
    for name, decl in cols:
        if name not in have:
            conn.execute(f"ALTER TABLE {table} ADD COLUMN {name} {decl}")

def migrate(conn):
    conn.executescript(_SCHEMA)
    _add_columns(conn, "plans", [("origin", "TEXT NOT NULL DEFAULT 'manual'"),
                                 ("market", "TEXT")])
    # WP15 R2（2026-09-16 审查）：超时回收与「真的尝试过并失败」分开计数
    _add_columns(conn, "research_tasks", [("timeouts", "INTEGER NOT NULL DEFAULT 0")])
    # ... WP11/12/14 各自的 _add_columns 追加（新表走 _SCHEMA）
    row = conn.execute("PRAGMA user_version").fetchone()[0]
    if row < SCHEMA_VERSION:
        conn.execute(f"PRAGMA user_version={SCHEMA_VERSION}")
    conn.commit()
```

### 2.4 UI 文案规范（沿用 WP1–5 索引 §2.1，全文有效）

系统页面文案只保留三类：数据事实（来源/as_of/降级原因）、操作反馈、安全合规必需
（SIM/LIVE 徽章、口令提示、一行免责）。规格引用、设计原则、边界解说一律写进代码注释，

「规格|设计稿|示例|宁可|窄门|token」即违规。
