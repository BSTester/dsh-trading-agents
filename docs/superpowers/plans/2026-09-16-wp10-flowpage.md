**目标**：新增「流程」页——每市场一条端到端阶段链（sync/quality/factors/plan/execute/reconcile/digest），只读既有事实，可下钻；auto_pipeline 开关进设置页（不进 MCP 工具面）。

**架构**：服务侧一个只读聚合端点 `pipeline`（事实来源=kv ran 标记 + plans/orders/alerts 表）；Web 侧新页 `pipeline.jsx`（antd Steps）+ settings.jsx 加开关区块；settings_api 扩展 `auto_pipeline` 读写。
