# P4 · 实盘交易操作手册（小额起步 · 风控 · 人工确认）

> 实盘是唯一需要你亲自决策并确认的环节。本手册把正确顺序与安全参数固定下来，
> 框架已全部就绪，剩余的是你按本手册在会话里逐步执行。

## 0. 前置条件（一次性）

1. 富途/牛牛账号已在 App 内开通 API 权限；
2. OAuth 授权时加了 `--write`（否则只有只读，无法下单）：
   ```bash
   python ~/.dsh/.agent-presets/dsh-trading-agents/scripts/futu_auth.py --write
   ```
3. 重启 harness 后，确认会话里有 `trading_order_place` 等真实交易工具。

## 1. 正确启动顺序（严格按此）

```
① 模拟盘跑通至少 2~4 周（P3 闭环），确认策略/信号稳定为正
② 确认当前模式是 sim：python scripts/trade_mode.py
③ 首笔实盘前，先在模拟盘完整走一遍"下单一改单一撤单"
④ 用户明确表示"开始实盘"后：python scripts/trade_mode.py live
⑤ 会话 AI 读取开关 → 确认 live → 展示订单摘要 → 你逐字确认 → 下单
⑥ 每笔实盘订单都再次逐字确认（见 §3）
```

## 2. 风控默认参数（改参数前先想清楚）

| 参数 | 默认 | 说明 |
|---|---|---|
| 单笔风险 | 权益的 1% | `RISK_PER_TRADE` |
| 止损 | 入场价 − 2×ATR | `STOP_ATR_MULT` |
| 最大持仓数 | 5 | `MAX_POSITIONS` |
| 单日亏损熔断 | 建议 3% | 达到即当日停手 |
| 实盘首笔金额 | ≤ 权益 2% | 验证链路为主，非盈利 |
| 账户模式 | 默认 sim | 每次重启后仍 sim，需显式切 live |

## 3. 人工确认流（不可跳过的字面流程）

下单前 AI 必须展示，且你必须逐字回复确认：

```
账户：live（真实）
标的：<代码>
方向/数量/价格：<买入 X 股 @ 限价 Y>
有效期：DAY
预计金额：<金额>，佣金≈<费用>
确认下单吗？请回复「确认下单」
```

实盘工具若返回 `need_order_confirm=true`，AI 还会调用 `trading_order_confirm` 做**系统级二次确认**——同样需你确认。

## 4. 首笔小额建议

- 选你熟悉的、流动性好的标的（如 00700.HK）；
- 金额 = 权益 2% 以内，目的仅验证"下单→成交→撤单→查询"链路；
- 完成后立即用 `account_orders_history`/成交记录核对，再决定是否继续。

## 5. 常见坑

- **忘了 `--write` 授权** → 只能查不能下单；
- **重启后模式回到 sim** → 实盘前必查 `trade_mode.py`；
- **切 live 后忘了切回 sim** → 收工即切回，习惯性 `trade_mode.py sim`；
- **市价单滑点** → 优先限价单，避开开盘/收盘时段。
